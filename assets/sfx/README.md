# Звуки

Файлов здесь намеренно нет, и звук по умолчанию **выключен флагом**
`SOUND.enabled` в `src/config.js`. Без флага браузер писал бы в консоль
по 404 на каждый ненайденный файл — для публикуемой игры это мусор.

Почему не положены сразу: взять CC0-наборы можно только руками, страницы
Kenney и OpenGameArt отдают архивы через форму, а генерировать звук
процедурно запрещает §2 `CLAUDE.md` — модераторы Playgama помечают такой
звук как AI-generated.

## Что скачать

- **Kenney Interface Sounds** — https://kenney.nl/assets/interface-sounds (CC0)
- **Kenney UI Audio** — https://kenney.nl/assets/ui-audio (CC0)
- OpenGameArt, фильтр по лицензии CC0 — https://opengameart.org

Формат — **`.wav`**. `.ogg` брать нельзя: §2 прямо предупреждает, что он
нестабилен в Safari и на iOS.

## Какие файлы нужны

Имена заданы в `SOUND.bank` в `src/config.js`, там же громкость каждого.

| Файл | Когда играет | Что подойдёт |
|---|---|---|
| `click.wav` | ручной клик | короткий сухой щелчок |
| `crit.wav` | крит | звонкий, ярче обычного клика |
| `buy.wav` | покупка уровня | подтверждение, «касса» |
| `deliver.wav` | коробка раскрылась | глухой удар с призвуком |
| `denied.wav` | не хватает ватт или денег | низкий отказ |
| `overheat.wav` | вход в троттлинг | тревожный сигнал |
| `cooled.wav` | выход из троттлинга | облегчение, мягкий тон |
| `clean.wav` | протёрли пыль | шорох |
| `order.wav` | пришёл заказ | уведомление |
| `reward.wav` | заказ выполнен | награда |
| `prestige.wav` | переезд | торжественный аккорд |

1. Положить файлы сюда.
2. В `src/config.js` поставить `SOUND.enabled: true`.
3. Обновить страницу.

Проверить, что подхватилось: `SETUP.sound.status()` в консоли — он покажет
списки `loaded` и `missing`. Чего не хватает, то просто молчит: одного
недостающего файла достаточно, чтобы пропало одно событие, а не звук целиком.

## Проверка перед публикацией

Тегов `<audio>` и `<video>` в игре нет и быть не должно:

```js
document.querySelectorAll('audio, video').length === 0
```

Весь звук идёт через Web Audio API из `src/platform/sound.js`.
